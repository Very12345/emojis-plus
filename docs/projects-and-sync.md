# 项目保存与 Agent 成品同步

## 使用

- 顶部“我的项目”或项目条的“历史作品 / 打开”进入项目库。可搜索名称与文案，打开编辑、重命名、复制、备份或删除非当前项目；删除前需确认。
- 第一次编辑会创建项目。停止修改约 700ms 后自动保存，项目条显示等待、保存中、已保存或错误。主动切换、新建和载入 Agent 成品前，先等待当前项目保存。尚有未保存内容时关闭页面会由浏览器提醒。
- 每个 AI 候选、Agent 成品都保留独立项目，保存方案和二进制成品。重新打开仍可调整人物、文本、道具和动作；修改后重新渲染，旧图不会被当作新方案的可下载成品。
- 备份为 `.emojis.json`，包含方案、成品和用到的个人导入图片，以及浏览器注册定义。导入会创建新项目，不覆盖原项目。含新增个人素材的备份导入后请刷新再打开，使选角列表同步更新。
- 也能导入 Skill 客户端保存的结果 JSON 或完整 Plan JSON，恢复方案后由浏览器重新绘制。普通 JPG/GIF 没有编辑参数，无法从图片还原图层。

## 连接与成品

“AI 已配置”指当前浏览器配置了模型；“Agent 接入 · 已连接”才表示通信桥已经注册此浏览器。通信桥进程启动本身不会自动配对一个从未授权的浏览器。

首次打开 Skill 的配对链接即可连接，链接中的配对信息随即从地址栏移除。也可以手动填写地址和配对码。此后配对记在该网站的浏览器存储中，刷新与短暂断网后会自动重连。点击“断开并暂停自动连接”可停止重连。浏览器仍需允许页面访问本机或局域网。

同一来源的标签页通过 Web Locks 共用一条传输连接，BroadcastChannel 传播连接状态、制作过程和已保存的成品项目 ID。连接所在标签页关闭后，其余页面接管。不同网站来源、浏览器或设备仍是不同工作台，Agent 应显式选择目标浏览器。

Agent 成品先写入本地项目库，再上传通信桥。默认自动打开第一份成品，当前创作先保存，拖动手势结束后再切换；面板中可关闭自动打开。每份成品还有独立编辑与下载入口。API 返回的文件描述增加 `project_id`，不暴露项目库读取或模型配置接口。

通信桥 v1.1 重启复用已有配置文件中的配对码。`--rotate-token` 显式更换配对码后，浏览器需要重新配对。重连同一个逻辑浏览器时保持其 ID（同一次通信桥进程内），更新私有传输凭据，中止正在执行的旧任务并提供可重试错误；不静默重放制作任务。进程重启后 Agent 应重新查询浏览器列表。

## 保存边界与冲突

项目保存在 `emojis-plus-projects-v1` IndexedDB，原素材与注册数据仍在原数据库，不升级原库以免阻塞仍打开的旧版页面。AI 配置和配对码不进入项目备份，也不进入静态构建或 Skill ZIP。

两页同时修改一个项目时，事务检查版本内容并为发生冲突的修改另存“此页副本”；没有新修改的旧页面不会覆盖别页新内容。名称修改与内容保存分开处理。保存空间不足时明确显示失败，阻止自动切换丢弃内容；预览缓存失效不阻碍保存方案。

数据只属于当前浏览器和网站来源。清理网站数据、无痕会话结束或浏览器回收存储都可能删除项目；请用备份保存重要作品。局域网 API 接通不意味着不同设备的项目库互相同步。历史功能从本版开始积累；此前已经关闭且未导出方案的临时创作无法追溯恢复。
