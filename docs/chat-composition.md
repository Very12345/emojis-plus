# 面向聊天发送的构图与可读性

本次修正针对新制作的表情，而不是通过添加无关场景填满背景。原模板、主题、组合和已有项目的 ID 保持不变。

## 默认行为

- 新 Agent `compose` 和浏览器 AI 推荐默认使用紧凑的聊天构图：大人物、靠近人物的主文案、较短且可省略的铺垫。
- 默认主文案使用56设计字号、加粗、深色、自然字距；在256成品中为28px，在128聊天预览中为14px。较长的新文案选择48设计字号，但不会删字。后续编辑遵守已有固定字号规则；换行不悄悄缩小字号，放不下则提示或由用户重新排布。
- 按实际透明主体边界加载素材，布局中将人物底部靠近文案，并保留原比例。单人、双人和多人使用各自站位；人物仍可直接拖动、缩放、旋转，个人动作及道具绑定继续生效。
- 特殊模板保留自己的布局。`render` 和已有完整方案默认原样渲染，不强制重排旧作品。`presentation: "original"` 可用于刻意留白的原布局。

## 追逐打闹

`interaction: "chase"`、`chaser_index: 0 | 1` 明确追赶者身份，要求两个人物。0是主角色，1是配角。两人有独立的前后站位、接近、弹跳和倾斜，并带方向线与短暂漫画碰撞标记，默认2.4秒循环；固定时序与文字位置不随帧重排。静图使用有表达内容的代表姿态。

这属于利用现有素材的程序化构图与动作，不能凭空补出素材中没有的四肢、拳头或绘画姿态。角色动作和画风的表现力仍取决于所选原素材。背景及装饰只服务于追逐关系，不以无关背景填空。

## 工作台与 Agent

大预览下方增加128×128成品预览与基础检查，提示人物太小、字体偏小或偏细、文案离主体太远、主文案遮挡人物等问题。检查不等于美感或笑点保证，最终仍需看实际小图。

“一键紧凑排版”保留文字、身份、字体家族和用户道具，重新安排人物与主副文案；锁定的人物、主副文案需先解锁。两人画面还可选择追逐、指定追赶者或关闭追逐动作。模板切换会清理不兼容的聊天动作配置。

AI输出增加互动和追赶者字段，不把“追着打”仅实现为两人并排。候选素材排序补充角色别名和互动情绪匹配；指定主角色时仍允许选择其他身份的配角。普通校园语境仍不自动引入学校角色。

API成品的 `info.quality` 包含 `warnings`、`subject_height`、`text_px_at_128`。新版Skill要求Agent查看实际小图及这些提示，并提供追逐调用示例。模型配置仍保存在各自浏览器，本次没有改动密钥或运行中的局域网通信桥。

## 验证

以奶龙“喷泪大哭”和可爱大笨蛋“生气”的真实透明素材，复现旧默认排版并输出新排版。128px主文案由8.5px提升至14px，最大人物高度占画布比例由约0.36增至0.51，图文大间距消除。此指标只针对该用例，不代表所有素材和表情自动达到同等效果。

50项回归通过，新增检查覆盖真实素材、128px文字、两个追逐人物分别移动、原GIF逐帧播放、256/512完整动作边界、实际GIF导出、固定字号换行、非法模式/追赶者、模板切换兼容和AI主配角身份校验。真实浏览器也通过Python客户端生成并下载24帧、2.4秒GIF，验证自动进入画布、128px预览和继续编辑。

复现：`npm test`，新用例输出在 `examples/chat-ready/`，包含旧默认复现、新静图、128px小图、对照图、GIF和尺寸指标。该旧图是可复现的默认行为示例，不冒充用户截图的原始制作参数。
