# 多角色共享动效修复

问题：普通排版和动态模板中，同框角色的局部方案把`effect`替换为角色自己的值、把`effects`清空、把`template_motion`关闭。因此右侧添加的共享伸缩、旋转等效果仅主角色生效，角色复制波浪也只创建主角副本。

修复：共享额外动效现在作用于全部人物，同框角色的附加效果独立合并。同名共享/个人效果执行一次，使用个人参数；不同效果叠加。模板角色动作同样继承，模板动作开关与共享额外动效保持独立。复制波浪覆盖各角色，逐字出现仍只处理文案。新增角色动效强度、速度控件，界面标明各设置的作用范围。

本机静态首页`/`改为`Cache-Control: no-cache`，避免继续从一小时缓存读取旧HTML。服务已重启，刷新页面可加载新脚本。

验证：`npm test`14项通过、`npm run build`通过；新增回归覆盖2/4/6人、普通和动态排版、7种共享变换、复制波浪、单角色效果叠加/去重、模板开关。98+192张样例重新构建。浏览器四人组合实际下载20帧GIF，并验证单角色独立效果控件，控制台无错误。

证据在`examples/cast-motion-fix/`：`before.gif`、`after.gif`、`contact.png`、`workbench.png`和`frame-comparison.json`。同一20帧四人组合的四个区域，相对首帧的累计显著变化像素，修复前为37381/4/48/524，修复后为38359/47471/45195/63850。少量静态区域差异可能来自GIF调色；联系表可直接核对动作。
