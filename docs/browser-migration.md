## 打包与限制

dist约253.5MiB，含约249MiB素材和字库。扫描无backend/data/.env/SQLite/Python文件；`/api/assets`、`/.env`、`/data/emojis.db`在静态服务均返回404。详见`distribution-check.json`。旧密钥未读入静态目录，也没有自动拷贝到浏览器。

AI适配器的解析、校验、最多一次重试和CORS提示已做模拟测试；本轮未使用真实模型账户调用，需在各使用者浏览器填写可用且允许CORS的接口。浏览器本地导入不自动同步到其他访问者。机器人排除规则不能充当访问控制。资源许可与来源标注保留，未对第三方素材权利作额外授权判断。

桌面、手机截图为`desktop.png`与`mobile.png`。浏览器临时测试标签页及8017测试服务已关闭；8000静态服务继续运行。
