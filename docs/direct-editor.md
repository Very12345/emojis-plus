# 预览直接编辑与多文字层

预览默认进入“直接编辑”。点击文字、人物，或使用“选择画面元素”下拉框。拖动移动、右下控制点等比缩放；文字右侧控制点只改变宽度，上方控制点旋转。双击文字或点“改文字”输入内容，Ctrl+Enter完成，Escape取消。选中画布后方向键移动1个导出像素，Shift+方向键移动10像素；移动时提供画布中心对齐线。

“＋ 添加文字”可添加最多10个独立文字层，叠加在模板原有主文案/第二段文案上。各层内容、字号、位置、宽度、旋转独立；新增层还能单独选字体和颜色。默认字号和字库仍在右侧，已单独设置的字号不被默认字号覆盖。删除或“重置布局”只影响所选元素；模板内已有的底图文字无法拆开编辑。

字号默认固定：换行/自动折行不会缩小字体，渲染器扩展文字区域高度。超出整个画布时明确报错，保留内容；可以减少字号、扩大文字宽度或主动勾选“自动缩字”。字号控件显示当前导出画布的实际像素；切换256/512画布会等比例缩放整个设计。

GIF编辑时暂停在清晰代表帧，点击“播放成品”查看真实循环。拖动过程中用同一Canvas核心即时绘制，不排队编码每个中间GIF；松手后才更新完整成品，未完成的结果不能下载。选择图片背景时可放大后拖动裁切，背景保持铺满画布。

人物自由布局与右侧人物参数同步。角色分身以同一角色组一起编辑；模板自带的装饰和动作算法继续由模板管理。切换模板/重新自动排布会恢复角色布局，文案和额外文字层保留。此轮不加入自由时间轴或草稿历史。

## JSON扩展

`Plan.text_boxes`按`text`、`secondary_text`保存模板文字区域；`Plan.text_layers`保存独立文字层，字段包括id/text/x/y/width/height/font_size/rotation/fit，以及可选font_family/text_color。`fit`为fixed或shrink，缺省fixed。位置和区域是0—1画布坐标；内部font_size使用512px参考画布单位，界面换算到当前导出像素。

`Plan.actor_transforms`按0—5角色编号保存画布中心x/y、相对模板的scale、附加rotation。`background_zoom`和`background_pan_x/y`控制背景裁切。缺省仍使用模板的自动布局。所有字段只在浏览器计算，不修改或上传AI密钥。

## 验证

保留原14项测试，新增5项：七字体在256/512下换行字号精确不变、自动缩字必须显式开启及超界提示、多文字层独立性与JPG/GIF、拖动框与实际人物像素边界一致、多图层校验/尺寸变换及背景裁切。98模板和192组合全部重新渲染。浏览器实测拖动文字/角色、缩放控制点、独立文字编辑和下载，并检查375px内容宽度无横向溢出。
